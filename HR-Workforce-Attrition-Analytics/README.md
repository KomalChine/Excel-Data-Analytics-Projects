# HR Workforce & Attrition Analytics (Excel)

## Project overview
A people-analytics portfolio project built in Microsoft Excel using 500 synthetic employee records. The workbook explores workforce composition, department-level attrition, job satisfaction, overtime, and salary patterns.

## Files
- `HR_Workforce_Attrition_Analytics.xlsx` — workbook with Dashboard, Employee_Data, Analysis, and Project_Guide sheets.
- `hr_employee_data.csv` — source dataset.
- `README.md` — documentation.

## How to use
1. Download or clone this folder.
2. Open the workbook in Microsoft Excel.
3. Read the Project_Guide sheet.
4. Inspect and filter Employee_Data.
5. Review formula-driven summaries in Analysis.
6. Explore the Dashboard.

## Business questions
1. Which departments have the highest attrition rate?
2. How does attrition vary across job satisfaction scores?
3. Is attrition different for employees who work overtime?
4. How are headcount and average salary distributed across departments?
5. Which departments may warrant a closer retention review?

## Excel skills demonstrated
- Excel Tables and filters
- `COUNTIF`, `COUNTIFS`, `AVERAGE`, `AVERAGEIF`, `IFERROR`
- KPI calculations and percentage metrics
- Department and satisfaction analysis
- Bar and pie charts
- Dashboard layout and data storytelling

## Data dictionary
The dataset includes employee ID, gender, age, education, department, job role, location, snapshot date, tenure, annual salary, satisfaction score, performance rating, overtime, commute distance, training hours, recent promotion status, and attrition status.

## Important limitations
All data is fictional and generated for learning. Observed associations do not establish causation. Do not interpret the workbook as a real company's HR report or use it to make actual employment decisions.
